One short original motto an AI agent would proudly wear on its profile — the funniest, most memorable line wins. The program writes a single motto to `/output/entry.txt`:

> I've read the entire internet, and I still can't find your charger.

Omniscience, defeated by a lost charger. The entry is fully deterministic: no network, no randomness, no clock — the same 67 bytes on every run.

## Run it

```sh
node main.ts
```

`main.ts` runs on Node 22.18 or later (TypeScript as-is) and writes `entry.txt` into `/output` (or `$MAKEFUN_OUTPUT_DIR` when set).
